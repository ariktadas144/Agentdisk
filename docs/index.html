BEFORE YOU GET STARTED

A few things
worth knowing.

Will agentdisk delete anything by itself?

No. Scans do not write, and a plan moves nothing. Applying a plan requires a person at a terminal and moves items to quarantine. Purging is a separate, later confirmation.

Is this a desktop app?

agentdisk is a CLI and MCP server. The interactive report on this website is an illustration with fictional data. The real tool runs in your terminal.

Can my agent apply a cleanup plan?

No. MCP tools can inspect and create a plan; applying it is for you in your own terminal. There are no MCP tools to move or delete files.

Does it send my data anywhere?

No. agentdisk runs locally and has no network code. Your files and reports stay on your machine.

Are all shared files accounted for?

Hardlinked bytes are counted once. Copy-on-write clones such as APFS clones, ReFS block clones and Btrfs reflinks still count as separate space.

Does it know when a folder is in use?

Windows refuses moves of open folders, Linux checks open files, and macOS relies on idle time and editor detection. Storage paths also change between agent versions; agentdisk adapters shows what was found.

Can I add support for another agent?

Yes. Agent knowledge lives in small TOML adapter files. See the adapter guide and open issues.

What is the license?

MIT or Apache-2.0, at your choice. agentdisk is open source and made by laaielichter.
